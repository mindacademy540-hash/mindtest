MIND Academy Website
====================

Files:
- index.html: Main website
- style.css: Responsive styling and MIND-inspired colors
- script.js: Mobile navigation, scroll animations, active navigation, and registration email flow
- assets/mind-logo.png: Provided MIND logo

How to run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. For development, open the folder in VS Code and use Live Server.

Registration:
- The registration form opens the visitor's default email app with a prepared message addressed to mindacademy540@gmail.com.
- The visitor must review and press Send. This static website does not store submissions or send emails in the background.
- Phone, Instagram, Facebook, and LinkedIn links are included.

Notes:
- This is a static HTML/CSS/JS website; no backend/database is configured.
- Google Fonts are loaded online.
